# Project history and attribution

**2023 — Original engineering project.** Matthew Coyle designed and built the Bluetooth/infrared prototype for the Bachelor of Engineering in Electronic and Computer Engineering at the University of Limerick. The project covered circuit design, an Android interface in MIT App Inventor, serial communication, infrared protocols, staged hardware testing and an enclosure designed in SolidWorks.

The original technical record was the final-year report, *Infrared Remote Control from a Mobile Phone* (March 2023). Publicly usable photographs, diagrams, application screenshots, functional outcomes and command mappings are incorporated directly into this repository so that readers can understand the engineering work without accessing that report.

**2026 — Software reconstruction and documentation.** The currently published Arduino sketch, C++11 command table, host tests and updated documentation were reconstructed from the original project's documented design, with AI assistance. These files are new material, not recovered 2023 source code. The recovered original editable firmware, App Inventor project and CAD source were not usable for this package.

The 2023 prototype operation and 2026 host-side software verification are distinct kinds of evidence; see [verification](verification.md).
